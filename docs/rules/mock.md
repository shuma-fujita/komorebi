# 🌳 Komorebi 3D｜モック運用ルール

## 1. 役割と確認先

- UIの試作・検証にはGitHub Pagesの `komorebi3d/mock.html` を使用する。
- チャット内へのHTML全文埋め込みや、モック専用チャットでの表示運用は行わない。
- 開発の相談・修正依頼・GitHubへのコミット・実機検証は原則「00｜統合開発」に一元化する。
- `mock.html` はUI検証用であり、ゲーム本体やバックアップの代わりではない。

## 2. UI変更の流れ

1. UIの変更内容を決め、GitHub `main` の最新ソースを確認する。
2. ユーザーの明示的な許可を得てモックを変更する。必要に応じて生成元と `mock.html` を整合させる。
3. GitHubにコミット後、GitHub Actions／本体 `dev.html`／モック `mock.html` の3つの確認リンクをまとめて送る。
4. モックの実機PASSを受けたら、改めて本体に反映し、本体側でも動作確認を行う。
5. ゲームロジックや性能の変更は、必要がなければモックを経由せず本体で開発する。

GitHubへの書き込み許可、固定Engine等の保護、検証結果の区別は `development.md` に従う。

## 3. 生成対象

`komorebi3d/build-dev.mjs` の生成対象はゲーム本体 `dev.html` とブラウザ確認用 `mock.html` のみ。
チャット専用HTMLと、その生成モードは使用しない。
